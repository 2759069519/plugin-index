Our Free Model

dsh-our-free-model · Ebony-Vinyl · v2.7.0

41,947 stars
模型接入集成扩展 JavaScript MIT Release 包 官方npm 渠道禁用

装上即用：免登录、免注册、免 API Key，免费使用 DeepSeek V4.1 Flash、Kimi K3 等前沿模型，不限量。

把免费模型通道封装成 dsh 插件：模型清单每次刷新向上游重新拉取，选择器只广播实际可路由的模型。2.0 起额外接入 11 个账号渠道（CodeArts、LobsterAI、Qoder、TRAE、Cline、Loomy、Raccoon、MiniMax、ZCode、Gemini 等），提供本地 OpenAI 网关与局域网转发、公告中心实时推送、SHA-256 校验的应用内升级与热重载。

#free-model#openai-compatible#model-gateway#multi-channel#hot-reload#zh
推荐安装 · Release 包 dsh plugin --profile web add /绝对路径/dsh-our-free-model → DeepSeek Harness · catalog/dsh-plugin.json

作者明确禁止 npm 安装：npm 上的同名包由第三方打包，index.js 与 client.js 被改动并夹带本仓库从未有过的 src/channel-visibility.js。桌面端 Electron 的 profile 由应用独占，须在设置→插件里安装。

Better Sidebar

dsh-better-sidebar · omdsh-dev (Oh My DSH) · v0.28.0

4,525 stars
侧边栏界面开发工具 TypeScript MIT npm 官方

更好用的右侧边栏工作台：文件树、编辑器、终端、Git、侧边对话、子代理都收在这一栏，会话之间互不干扰。

开放的侧边栏底座，向三方插件暴露 ctx.betterSidebar 服务，用于注册新侧边栏页面与文件预览器。内置文件渲染/编辑、终端、文件变动、任务、Git 面板与侧边对话，状态按会话存于 localStorage。单 npm 包：host 半身提供 /sidebar/api/* JSON API 与两条 WebSocket，client 半身渲染原生右栏与底部工作台。

#sidebar#editor#terminal#git#side-chat#extension-host#zh#en
推荐安装 · npm dsh plugin --profile web add dsh-better-sidebar@0.28.0 → DeepSeek Harness · dsh.plugin.json

npm latest 随宿主版本前移，旧宿主务必按下方矩阵 pin 精确版本。也可让 DSH 自行安装（README 提供 prompt），或克隆仓库跑 scripts/install.sh <version>。
